How it works

One lookup turns text into coordinates.

The enrichment runs while the data is collected. Nothing changes in the MIMO database.

01

MIMO registry

SQL database with country, city, site, building and room for every tablet.

02

Elastic Agent

Reads the registry every 15 minutes and sends one document per tablet.

03

GeoNames lookup

About 208,000 cities loaded once. Adds coordinates, country code and time zone to each document.

04

Kibana

Map and dashboard, filtered by country, site or building.
